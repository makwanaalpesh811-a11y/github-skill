# Create Repo — Example

## Copy-paste

```bash
# Create public repo
gh repo create test-repo --public
```

## Expected Output

```
Creating repository...
Created test-repo on GitHub
URL: https://github.com/username/test-repo
```

## Safety

- Requires: `gh` CLI + `GH_TOKEN`
- Dry-run supported: `gh repo create test-repo --public --dry-run`
